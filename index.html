Why the bot chose them

Best solve favours a word that can actually be the answer. Best information favours the guess that splits the remaining pool most evenly. Hybrid balances both. When the candidate pool is tiny, the same word may legitimately be best in more than one category.
This is a testing build. Batch archive mode automatically plays the bot against pasted historical answers; it does not control the live Wordle/Canuckle websites. Wordle answer/guess lists are loaded from public GitHub mirrors when available. Canuckle works best with an archive list pasted into Custom answer list.
